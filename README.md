# Atlas of the Elements

An interactive periodic table: 3D and 2D atoms, nuclei and orbitals, property heat maps, a temperature and discovery timeline, a chart of nuclides with decay chains, a molar-mass calculator and a quiz.

- `index.html` is the page GitHub Pages serves. Link to one element with its symbol, for example `#Au`.
- `atlas.html` is the source, also published as a claude.ai artifact.
- After editing `atlas.html`, run `node build.js` to rebuild `index.html`.
